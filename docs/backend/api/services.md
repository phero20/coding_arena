# API Services Breakdown

The backend follows a strict **Service Layer Pattern**, where all business logic is encapsulated in dedicated service classes.

## ⚔️ `ArenaService`
The most complex service in the system. It orchestrates the real-time competitive matches.
*   **Location**: `api/src/services/arena/arena.service.ts`
*   **Key Logic**:
    *   `createRoom()`: Initializes Redis room state.
    *   `ensureIsHost()`: Authorization check for room modifiers.
    *   `reconcileStatus()`: A "Sync-on-Read" mechanism that fixes Redis if it disagrees with MongoDB.
    *   `withLock()`: Uses Redis locks to prevent duplicate match starts during concurrent requests.

## 🤖 `AiCodeJudgeService`
Provides "Approximate Judging" using Large Language Models.
*   **Location**: `api/src/services/judge/ai-code-judge.service.ts`
*   **Workflow**:
    1.  Fetches problem description.
    2.  Builds a prompt containing User Code + Test Cases.
    3.  Calls Groq/Gemini to "Simulate" the run.
    4.  Maps LLM verdicts (ACCEPTED, TLE, etc.) to Judge0-compatible status IDs.

## 💎 `GeminiLlmService`
The interface for all Generative AI features (Problem Generation, AI Feedback).
*   **Location**: `api/src/services/ai/gemini-llm.service.ts`
*   **Techniques**:
    *   **Strict JSON Mode**: Uses `responseMimeType: "application/json"` to ensure parseable outputs.
    *   **Prompt Sanitization**: Implements profiles to prevent prompt injection and leaked descriptions.

## 📝 `ProblemService`
Handles the problem lifecycle and metadata.
*   **Location**: `api/src/services/problems/problem.service.ts`
*   **Features**:
    *   Slug-based retrieval (SEO friendly).
    *   Topic-based search for Arena matching.
    *   Upsert logic for syncing problems from AI generation.

## ⚙️ `Judge0Service`
The direct interface to the Judge0 execution engine.
*   **Location**: `api/src/services/judge/judge0.service.ts`
*   **Responsibility**:
    *   Making the POST request to the Judge0 API.
    *   Handling polling/callback for asynchronous execution.
    *   Passing the `ExecutionPackage` generated by the **Driver System**.
